# Bundled interface fonts

The application embeds unmodified **Noto Sans CJK SC 2.004** regular and bold
OpenType faces. These include Latin and Simplified Chinese glyphs so that the
interface and names render on systems without installed CJK fonts, including
Fyne's software test renderer. Symbol/monospace styles use Fyne's own fonts.

Source: [notofonts/noto-cjk, Sans2.004](https://github.com/notofonts/noto-cjk/tree/Sans2.004/Sans/OTF/SimplifiedChinese).
License: [SIL Open Font License 1.1](OFL.txt), retained from that tag's root LICENSE.
No font files are modified or generated by this project.
