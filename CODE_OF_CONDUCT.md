# Code of conduct

ImagePort welcomes contributors regardless of experience, background or identity.
Treat participants respectfully and make technical discussions useful to others.

## Expected behavior

- Be considerate, constructive and specific when giving feedback.
- Discuss ideas and evidence without attacking people.
- Respect different experience levels and help newcomers participate.
- Respect privacy, intellectual property and requests to stop unwanted contact.

## Unacceptable behavior

Harassment, threats, discriminatory language, sexual attention, personal attacks,
doxxing, publishing private information, and repeated disruptive behavior are not
acceptable in project spaces or when representing the project elsewhere.

## Reporting and enforcement

Contact a repository maintainer through an available private GitHub contact
channel. If no private channel is available, ask for one in a minimal issue
without disclosing personal details. Maintainers will protect reporter privacy
to the extent possible and assess reports fairly.

Maintainers may edit or remove inappropriate content, request a behavior change,
temporarily restrict participation, or exclude participants for serious or
repeated violations. Decisions should be proportionate, explain the violated
expectation and provide a path to appeal privately to another available maintainer.

This policy applies to issues, pull requests, code review and other project spaces.
